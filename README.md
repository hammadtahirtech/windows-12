# Windows-12 Concept

I originally built this project when I was 13 while learning frontend development. The goal was to recreate some familiar desktop features in the browser, including:

* Start menu
* Taskbar
* Theme switching
* Basic system actions
* Desktop-style UI

The code reflects where I was as a developer at the time, but I'm publishing it because it was one of the first projects I built that people genuinely enjoyed using and exploring.

This project is open source and preserved as part of my learning journey.
